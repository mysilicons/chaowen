# 朝闻 0.1.0

首个可用版本：把《人民日报》电子版变成可长期保存的个人报纸库。

> 本软件为个人独立开发，与人民日报社、人民网无任何关联，未获其授权或赞助。

## 安装

下载 `朝闻-0.1.0-setup.exe`，双击安装。

- 无需管理员权限（默认装到当前用户目录，也可切「所有用户」）
- 安装位置可自选
- 控制面板可卸载，卸载**不会**删除已下载的报纸与缓存

## 功能

**书架**
- 周视图快速切换 + 可展开的完整月历
- 按日浏览 20 个版面，缩略图优先读本地缓存
- 未来日期置灰，已归档日期带标记

**阅读**
- PDF 原版 / 文字模式双模式切换，共用一个阅读位置
- 文字模式按版组织，可逐篇翻阅、字号可调
- 深色模式

**下载**
- 单日下载与日期区间批量下载
- 下载中可暂停、继续、取消
- 每期 20 版自动合并为一个带书签的 PDF，单版自动清理
- 低速访问：1 并发 · 2 请求/秒（`RMRB_RATE` 可调）

**其它**
- 首次启动向导
- 历史日期的版面目录本地缓存，切换近乎零延迟
- 下载目录可自定义

## 已知限制

- 安装包**未做代码签名**，首次运行 Windows 可能提示「SmartScreen 已阻止」，点「更多信息 → 仍要运行」
- 只支持 2024-12-01 之后的 `/pc/` 新版站点
- 深色模式、暂停/取消等界面行为尚未经过大规模人工验证
