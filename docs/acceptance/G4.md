## 3. 本阶段完成项

### A-11 信息与路径（原「设置页」的收敛版）

未做完整设置页（下载目录选择、速度档位持久化需要配置系统），先做**关于对话框**：

- 引擎版本 / Python 版本 / 协议版本；
- 下载目录、缓存目录（可选中复制）；
- 合规声明。

理由：配置持久化属于 `settings.get/set` 的范畴，而目录选择还涉及"改目录后是否迁移文件"的交互，工作量大于剩余预算，**留到下一轮**。

### A-12 批量下载

- 引擎 `batch.start {from, to}`：先回执（天数/预估体积/预估耗时），再逐日执行；
- 单日失败不中断（`batch.day` 事件记录），继续下一天；
- 界面：快捷预设（近 7 天 / 近 30 天 / 本月 / 本年）+ 起止日期选择 + 预估（`7 天 · 约 441 MB · 约 6 分钟`）；
- 队列支持批量任务的按天进度。

### P-05 打包

- `scripts/package.ps1`：PyInstaller 引擎 → `flutter build windows --release` → 复制引擎进 Release → 输出便携目录；
- 引擎定位逻辑：优先 `<exe 目录>/engine/rmrb_engine.exe`，找不到再走 `uv run`（开发态）。
