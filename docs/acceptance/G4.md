## 11. PDF 未下载时的下载提醒（2026-10-29）

切到 PDF 模式且本期文件不存在时，弹出询问：

- 标题「本期还没下载」，说明体积与耗时（约 60 MB / 1 分钟）；
- 「先看文字」→ 自动切回文字模式；
- 「下载本期」→ 调用 `download.start`，占位区变成带进度条的状态页（第 N 版 / 共 M 版），
  监听 `issue.archived` 后失效 `issueStatusProvider`，PDF 自动出现，无需手动刷新。

判断依据是**文件是否真实存在**（`mergedPath != null && File(...).existsSync()`），
而不是状态库里写着 archived —— 文件被手动删掉时同样会提醒重新下载。
同一期只提醒一次（`_prompted` 集合）。
