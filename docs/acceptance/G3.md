## 4. 各任务验收

### E-10 正文抓取与缓存

| 检查 | 实际 | 结论 |
| --- | --- | --- |
| 单版抓取 | 第 1 版 8 篇，blocks 非空 | ✅ |
| 缓存命中 | 二次调用 0 请求（respx 断言 call_count 不变） | ✅ |
| refresh | `refresh=true` 绕过缓存，重新抓页面 | ✅ |
| 图片落地 | `cache/img/<sha1>.jpg` 存在，block.local 指向它 | ✅ |
| 单篇失败隔离 | 抛 `EngineError` 计数，不影响其余文章 | ✅ |
| 进度事件 | `article.progress` 每篇一条 | ✅ |

### E-11 版型判定

| 输入 | 判定 | 结论 |
| --- | --- | --- |
| 无文章 | `empty` | ✅ |
| 1 篇且正文 < 60 字 | `image_only` | ✅ |
| 1 篇且有正文 | `single` | ✅ |
| ≥2 篇 | `normal` | ✅ |
| 全部抓取失败 | `failed` | ✅ |

### A-07 PDF 面板

- `PdfViewer.file(path, key: ValueKey(path), controller, initialPageNumber)`；
- `controller.goToPage(pageNumber:)` 与版条联动；
- 未下载 / 文件不存在 → 提示"本期尚未下载"，不白屏。

### A-08 文字面板

| 检查 | 实际 | 结论 |
| --- | --- | --- |
| 标题 / 作者 / 段落 | 组件测试断言三者均渲染 | ✅ |
| 首行缩进 | 渲染时补 `\u3000\u3000`（引擎已剥离原文缩进） | ✅ |
| 字号调节 | `readerScaleProvider` 0.85–1.5，标题与正文同比缩放 | ✅ |
| 选中复制 | `SelectionArea` 包裹正文 | ✅ |
| 版心宽度 | `maxWidth: 720` 居中，长文不拉满屏 | ✅ |

### A-09 模式切换

`readerModeProvider`（text / pdf）+ `readerPageProvider` 分离，切换只改渲染器，页号保持不变。

### A-10 降级 UI

| 版型 | 表现 | 结论 |
| --- | --- | --- |
| `image_only` | 顶部黄条「本版以图片为主」+ 版面图 + 「看 PDF」 | ✅ |
| `empty` | 「本版无可提取正文」+ 切换 PDF / 重试 | ✅ |
| `failed` | 「本版正文解析失败」+ 重试 | ✅ |
