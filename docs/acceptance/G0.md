## 环境偏差与处理

| 问题 | 处理 |
| --- | --- |
| `selectolax 1.0.2` 移除了 Modest 后端，`from selectolax.parser import HTMLParser` 直接 ImportError | 改用 `from selectolax.lexbor import LexborHTMLParser`；主题为解析层，不影响设计 |
| `pyproject.toml` 声明了 `readme = "README.md"` 但文件不存在，`uv sync` 报 `OSError: Readme file does not exist` | 补 `engine/README.md` |
| 引擎 CLI 在 Windows 控制台输出中文为乱码（cp936） | `main()` 里对 stdout/stderr 调 `reconfigure(encoding="utf-8")`；该修复同时是 E-09 IPC 的前置条件 |
| `ruff` 报 `UP042`：`class ErrorCode(str, Enum)` | 改为 `StrEnum`（Python 3.12 原生） |
