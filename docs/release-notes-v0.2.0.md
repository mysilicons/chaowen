# 朝闻 0.2.0

在 0.1.0 的报纸存档能力之上，新增联合早报中国频道的阅读：一个应用里同时读报纸和新闻。

> 本软件为个人独立开发，与人民日报社、人民网、联合早报及新报业媒体均无关联，未获其授权或赞助。

## 安装与升级

下载 `Chaowen-0.2.0-setup.exe`，双击安装。

- **已经装过 0.1.0**：直接运行新安装包即可。安装程序会识别到旧版本，显示「升级」，沿用上次的安装位置，只替换程序文件；下载目录、已下载的报纸和设置都会保留。
- **首次安装**：默认装到当前用户目录，无需管理员权限；安装位置可自选，也可以选择「为所有用户安装」。
- 控制面板可卸载，卸载**不会**删除已下载的报纸与缓存。

## 新增：联合早报中国频道

- 侧栏新增「联合早报」，读取官网中国频道当前页面的文章列表
- 首页沿用纸色、宋体与轻量控件，头条区与分栏目录呈现新闻
- 滚动到底部自动加载更早的文章，也可以点「加载更早的文章」
- 点击文章，在朝闻内阅读提取后的文字与图片，可调字号、切换深浅主题
- 列表、正文、图片只驻留内存，不写入早报内容缓存；重新进入即请求最新列表
- 遇到访问限制或预览页会明确提示，可通过「原文」在系统浏览器查看

早报功能使用本机直接请求 `.com`，不主动切换到 `.com.sg`，不需要登录，不采集账号或 Cookie。它是网页文章阅读，不提供早报电子报 PDF 或历史整期下载。

## 改进

- **阅读页连续加载**：文章翻到底部可继续加载下一篇，分页状态不再错乱
- **诊断日志**：前端、引擎、原生崩溃各写独立日志，设置页可一键打开；不记录正文、标题、摘要、Cookie 或鉴权值
- **启动刷新**：进入联合早报即清空上一会话并请求最新列表，失败时明确报错
- **访问节奏**：移除旧版固定 10 秒等待，正文与列表默认请求间隔 0.5 秒；遇到 429 仍遵守服务端等待要求

## 人民日报部分

保持不变：周视图书架、PDF / 文字双模式阅读、单日与区间下载、暂停/继续/取消、每期自动合并为带书签的 PDF、低速访问（1 并发 · 2 请求/秒）。

## 已知限制

- 安装包**未做代码签名**，首次运行 Windows 可能提示「SmartScreen 已阻止」，点「更多信息 → 仍要运行」
- 人民日报只支持 2024-12-01 之后的 `/pc/` 新版站点
- 联合早报只读取官网当前列表与文章页，不提供历史整期或离线归档
