# 联合早报实施日志

日期：2026-10-30。遵循 ub-mode：先行为测试，再最小实现，最后整理与回归。

## 术语

- 频道快照：固定中国频道页面的一次主列表解析结果，不代表某日全部新闻。
- 文章：由快照直接发现的详情页，以 story ID 标识；不递归发现相关阅读。
- 正文块：有序段落或图片，复用现有阅读器的 Block 格式。
- 完整性：full / preview / unknown / unsupported，与访问条件分别存储。
- 任务：独立早报 worker 执行的刷新／抓取；主线程先回执，后台只推事件。
